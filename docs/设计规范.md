## macOS 桌面应用 UI 设计规范

**基于 macOS Human Interface Guidelines · 通用版**

---

### 1. 设计原则

| 原则 | 说明 |
|------|------|
| **清晰** | 信息层级分明，操作意图明确，避免歧义 |
| **高效** | 减少操作步数，常用功能触手可及 |
| **原生感** | 使用系统控件、系统字体、系统色彩语义，融入 macOS 生态 |
| **克制** | 不过度设计，非必要不增加视觉元素 |

---

### 2. 色彩系统

#### 2.1 语义色（跟随系统 Light/Dark Mode）

| Token | Light | Dark | 用途 |
|-------|-------|------|------|
| `background.primary` | `#FFFFFF` | `#1E1E1E` | 窗口/面板主背景 |
| `background.secondary` | `#F5F5F5` | `#2C2C2C` | 分组背景、侧边栏 |
| `background.tertiary` | `#E8E8E8` | `#3A3A3A` | 卡片、控件填充 |
| `text.primary` | `#1D1D1F` | `#F5F5F7` | 标题、正文 |
| `text.secondary` | `#6E6E73` | `#A1A1A6` | 说明文字、副标题 |
| `text.tertiary` | `#AEAEB2` | `#6E6E73` | 占位符、禁用态 |
| `separator` | `#E5E5EA` | `#38383A` | 分割线 |
| `accent` | `#007AFF` | `#0A84FF` | 系统强调色 |
| `success` | `#34C759` | `#30D158` | 成功/在线状态 |
| `warning` | `#FF9F0A` | `#FFD60A` | 警告/过渡状态 |
| `error` | `#FF3B30` | `#FF453A` | 错误/禁用 |

> **规则：** 优先使用系统语义色（`Color.primary`、`Color.secondary`、`Color.accentColor`），仅在需要状态区分时使用 success/warning/error。

### 3. 字体系统

统一使用 **San Francisco (SF Pro)**，macOS 系统原生字体。

| Token | 字体 | 大小 | 字重 | 用途 |
|-------|------|------|------|------|
| `largeTitle` | SF Pro | 22pt | Semibold (600) | 窗口主标题 |
| `title` | SF Pro | 17pt | Semibold (600) | 分组标题、卡片标题 |
| `body` | SF Pro | 13pt | Regular (400) | 正文、列表项 |
| `bodyBold` | SF Pro | 13pt | Semibold (600) | 强调正文 |
| `caption` | SF Pro | 11pt | Regular (400) | 辅助说明、状态标签 |
| `captionMono` | SF Mono | 11pt | Regular (400) | 数值、代码、路径 |

**规则：**
- 使用 SwiftUI 语义化字体（`.title2`、`.body` 等），跟随用户文字大小设置
- 标题用 `.bold()` 修饰，数字用 `.monospacedDigit()`

### 4. 图标系统

#### 4.1 来源

统一使用 **SF Symbols**（macOS 系统内置），不引入自定义图标包。

#### 4.2 规格

| 场景 | 尺寸 | 渲染模式 |
|------|------|----------|
| 菜单栏图标 | 18×18pt | Template (单色) |
| 面板/列表图标 | 16×16pt | Hierarchical |
| Tab 图标 | 20×20pt | Hierarchical |
| 按钮图标 | 14×14pt | Hierarchical |
| 状态指示圆点 | 8×8pt (`circle.fill`) | 单色填充 |

### 5. 布局规范

#### 5.1 菜单栏面板

| 属性 | 值 |
|------|-----|
| 宽度 | 固定 320pt |
| 最大高度 | 480pt（超出滚动） |
| 内边距 | 16pt |
| 列表行高 | 44pt |
| 行间距 | 4pt |
| 面板圆角 | 12pt |

面板结构（自上而下）：权限引导（未授权时）→ 显示器状态列表 → 分割线 → 智能暂停提示行（命中时）→ 操作行（暂停播放 / 设置… / 退出）→ 分割线 → 开机自启开关行。智能暂停命中时「暂停播放」开关灰显。

#### 5.2 设置窗口

| 属性 | 值 |
|------|-----|
| 最小尺寸 | 620×440pt |
| 内容区内边距 | 20pt |
| Tab 栏高度 | 36pt |
| 标签列宽 | 120pt |
| 行间距 | 20pt |

#### 5.3 间距 Token

| Token | 值 |
|-------|-----|
| `spacing.xs` | 4pt |
| `spacing.sm` | 8pt |
| `spacing.md` | 12pt |
| `spacing.lg` | 16pt |
| `spacing.xl` | 20pt |
| `spacing.xxl` | 32pt |

### 6. 组件规范

#### 6.1 按钮

| 类型 | 样式 | 用途 |
|------|------|------|
| 主要操作 | `BorderedProminent` + accent | 保存、确认 |
| 次要操作 | `Bordered` | 取消、关闭 |
| 危险操作 | `Bordered` + red | 删除、不可逆 |
| 图标按钮 | `Borderless` + SF Symbol | 添加、刷新 |
| 文本按钮 | `Link` 样式 | 引导链接 |

#### 6.2 输入控件

| 控件 | 用法 |
|------|------|
| 滑块 `Slider` | 标签 (100pt) + 滑块 (200pt) + 数值 (40pt) |
| 下拉 `Picker` | 样式 `.menu`，宽度自适应，最大 200pt |
| 开关 `Toggle` | 标签在左，开关在右 |
| 文本输入 `TextField` | 宽度自适应容器，占位符用 `text.tertiary` |

#### 6.3 状态指示

| 元素 | 规格 |
|------|------|
| 圆点 | 8pt, `circle.fill`, 颜色区分状态 |
| 标签 | 11pt, `text.secondary`, SF Symbol 图标前缀 |
| 暂停状态行 | 12pt caption, 中粗；原因列表用「、」分隔；跟随命中条件显示 |
| 命中状态行 | SF Symbol（`checkmark.circle` 绿 / `pause.circle.fill` 橙）+ caption 描述（设置窗口「智能暂停」分区底部） |

#### 6.4 卡片

| 属性 | 值 |
|------|-----|
| 背景 | `background.tertiary` |
| 圆角 | 8pt |
| 内边距 | 12pt |
| 间距 | 12pt（网格布局） |

#### 6.5 空状态

```
[图标]  48pt, SF Symbol, text.tertiary
标题    title, text.secondary
描述    body, text.tertiary
按钮    Bordered, accent
```
垂直居中，间距 12pt。

#### 6.6 分割线

| 属性 | 值 |
|------|-----|
| 颜色 | `separator` |
| 粗细 | 1pt |
| 左右内边距 | 16pt |

### 7. 动效规范

| 动效 | 时长 | 曲线 |
|------|------|------|
| 面板展开 | 0.15s | `.easeOut` |
| 面板收起 | 0.10s | `.easeIn` |
| Tab 切换 | 0.20s | `.easeInOut` |
| 悬停效果 | 0.15s | `.easeOut` |
| 状态切换 | 0.30s | `.easeInOut` |

**规则：**
- 使用系统预设曲线：`.easeIn` / `.easeOut` / `.easeInOut`
- 检测 `reduceMotion` 并在开启时禁用所有动效

---

### 8. 窗口行为

| 场景 | 行为 |
|------|------|
| 菜单栏面板 | 点击图标 toggle；点击外部自动收起；ESC 收起 |
| 模态窗口 | 居中显示，背景半透明遮罩，阻止操作父窗口 |
| 设置窗口 | 标准标题栏，关闭时自动保存，不可全屏 |
| 工具栏 | 位于窗口顶部，高度 36pt，纯图标或图标+文字 |

---

### 9. 无障碍规范

| 要求 | 实现 |
|------|------|
| 标签 | 所有交互元素提供 `accessibilityLabel` + `accessibilityHint` |
| 数值 | 滑块等控件提供 `accessibilityValue`，包含单位 |
| 键盘 | 支持 `Full Keyboard Access`，Tab 切换焦点 |
| 适配 | 检测 `reduceMotion`、`reduceTransparency`、`highContrast` 并响应 |

---

*本规范基于 macOS Human Interface Guidelines，适用于 SwiftUI + AppKit 混合项目。*

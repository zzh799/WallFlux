## 产品需求文档（PRD）

### 1. 产品概述

**产品名称：** WallFlux

**一句话描述：** 一款 macOS 菜单栏应用，能独立为每个显示器配置动态壁纸；闲置的显示器自动循环播放动态壁纸以保护屏幕，活跃的显示器则进入几乎不可察觉的微跳模式以避免烧屏，全程不打扰用户。

**目标平台：** macOS 14+（Sonoma 及以上）

**运行形态：** 菜单栏常驻应用，静态图标，点击弹出控制面板。

---

### 2. 用户场景

| 场景 | 描述 |
|------|------|
| 多显示器办公 | 用户有 2-3 台显示器，主屏用于工作，副屏在闲置时自动播放动态壁纸充当屏保 |
| 短暂离开 | 用户离开工位 5 分钟，所有显示器自动开始播放动态壁纸 |
| 回来继续工作 | 鼠标回到某显示器，壁纸立即停止/渐隐退出，恢复桌面 |
| 笔记本 + 外接 | 用户插拔外接显示器，程序自动识别并恢复之前配置 |

---

### 3. 功能需求

#### 3.1 核心功能：闲置检测与动态壁纸播放

- **FR-01：闲置判定**
  - 基于用户输入超时：某显示器上超过 N 分钟无鼠标移动/键盘操作，判定为"闲置"
  - 鼠标所在显示器始终视为"活跃"；键盘操作让所有显示器变为活跃
  - 闲置阈值 N 支持用户自定义（默认值建议 5 分钟）

- **FR-02：闲置显示器行为**
  - 闲置显示器自动创建覆盖窗口，循环播放动态壁纸，**播放期间窗口置于顶层**（屏保层级，覆盖普通窗口与菜单栏），类似屏保效果
  - 鼠标短暂进入播放中的显示器时，壁纸**立即降到底层让位**（桌面图标层级）并暂停，用户可立即看到并操作屏幕内容；宽限期（默认 5 秒）内鼠标移出或停止移动，则恢复顶层继续播放
  - 活跃显示器壁纸窗口位于桌面图标之上、普通应用窗口之下，不遮挡工作窗口

- **FR-03：活跃显示器行为（微跳模式）**
  - 活跃显示器保留壁纸窗口但不播放（暂停）
  - 每隔 Y 秒自动向前跳 Z 帧后立即暂停
  - Y 和 Z 均支持用户自定义（默认建议 Y=15 秒，Z=1 帧）
  - 微跳起始帧为壁纸退出时的最后一帧，无缝衔接
  - 目的是在几乎不被察觉的前提下避免屏幕烧屏
  - 存在全屏或最大化的应用窗口时可暂停微跳（默认开启，可配置）：避免在应用窗口之上持续跳帧；退出全屏后自动恢复，不影响闲置屏屏保播放

- **FR-04：退出机制**
  - 显示器从闲置变为活跃时，壁纸退出
  - 退出行为可配置：立即停止 / 渐隐过渡（默认 0.5 秒淡出）
  - **短暂进入宽限**：鼠标进入闲置显示器不立即退出，壁纸先降层让位；宽限期（默认 5 秒，可配置）内鼠标移出或停止移动则恢复置顶播放，持续移动满宽限期才判定为真实使用并退出
  - 点击、滚动、拖拽、键盘输入视为强交互，立即退出不走宽限

#### 3.2 壁纸素材管理

- **FR-05：素材来源**
  - 支持 macOS 系统自带动态桌面壁纸
  - 支持用户导入本地视频文件（mp4、mov、webm 等）
  - 支持用户导入本地图片序列（文件夹内图片按文件名排序作为帧序列播放）

- **FR-06：素材分配**
  - 每个显示器可独立选择不同的壁纸素材
  - 素材库统一管理，所有显示器共享同一素材池

#### 3.3 多显示器管理

- **FR-07：逐显示器独立配置**
  - 壁纸内容按显示器独立设置
  - 其余参数（闲置阈值、微跳间隔/帧数、退出方式）全局统一

- **FR-08：热插拔支持**
  - 自动检测显示器连接/断开
  - 通过显示器唯一标识符记住每个显示器的壁纸配置
  - 重新接入时自动恢复之前的壁纸

#### 3.4 菜单栏交互

- **FR-09：菜单栏图标**
  - 静态图标，不随状态变化

- **FR-10：菜单栏面板**
  - 点击图标弹出紧凑控制面板
  - 显示当前各显示器状态（活跃/闲置/已暂停原因）和对应壁纸名称
  - 提供快速暂停/恢复开关；智能暂停命中时开关灰显并展示命中原因与解决指引
  - 提供开机自启开关（与设置双向同步）
  - 提供进入完整设置的入口

#### 3.5 设置界面

- **FR-11：全局设置**
  - 闲置判定超时 N（默认 1 分钟，范围 1-60 分钟）
  - 微跳间隔 Y（默认 30 秒，范围 1-300 秒）
  - 微跳帧数 Z（默认 10 帧，范围 1-10 帧）
  - 退出方式：立即 / 渐隐过渡
  - 短暂进入宽限期（默认 5 秒，范围 0-60 秒；0 表示鼠标进入立即退出）
  - 其他应用播放媒体时保持活跃开关（默认开启）：见 FR-16

- **FR-12：显示器壁纸设置**
  - 配置方式单选：所有显示器（统一壁纸）/ 单独设置（逐显示器），横向排布在顶部工具栏；「单独设置」模式下工具栏内联显示器选择菜单
  - 顶部工具栏右侧提供「立即播放动态壁纸」：无需等待闲置超时，目标显示器立即进入闲置循环播放（等效闲置超时触发，供即时预览），任意输入即退出；手动触发为显式操作，不被媒体播放守卫（FR-16）阻断（预览期间媒体守卫不生效，退出闲置后恢复）
  - 壁纸来源为左右分栏浏览器：左侧选择来源（系统壁纸 / 导入视频 / 导入图片序列），右侧以缩略图网格预览该来源全部素材（缩略图异步生成并建立缓存），点击素材即应用；切换素材时保持闲置播放状态
  - 素材管理集成在来源分栏中：视频来源提供「导入视频」，图片序列来源提供「添加文件夹」，导入素材可直接在网格中删除

- **FR-13：素材管理（集成于 FR-12 的壁纸来源分栏）**
  - 导入视频文件（视频来源分栏）
  - 导入图片文件夹（图片序列来源分栏）
  - 浏览/删除已导入素材（素材网格）

#### 3.6 智能暂停与开机自启

- **FR-14：智能暂停**
  - 二值暂停模型：任一启用条件命中即**完全暂停**（停播放 + 停微跳），无降频中间态；条件全部解除自动恢复
  - 手动暂停与智能暂停为**独立暂停源**，任一命中即暂停（OR 合并）；智能暂停命中时面板恢复按钮灰显，不允许手动覆盖
  - 全局条件（命中作用于全部显示器）：系统睡眠 / 显示器睡眠 / 低电量模式 / 电池供电 / 低电量阈值
  - 低电量阈值默认 40%（范围 5-50%），恢复线 = 阈值 + 5% 防抖滞后；与是否插电无关，充电时同样生效
  - 系统唤醒后所有显示器重置为活跃（唤醒后壁纸不立即置顶播放）
  - 智能暂停总开关 + 各条件开关可独立启停；关闭时回归纯手动控制
  - 设置窗口提供「智能暂停」分区（总开关 + 5 个全局条件 + 阈值滑块 + 当前命中状态行）

- **FR-15：开机自启**
  - 使用系统登录项 API（`SMAppService.mainApp`），系统状态为真相源，不冗余存储布尔值
  - 默认关闭，不静默开启；首次启动弹窗询问（UserDefaults 标记，只询问一次）
  - 菜单栏面板与全局设置「启动」分区双向同步，开关状态以系统为准
  - 处于「已注册但需系统批准」状态时展示警示 + 「打开系统设置」按钮引导

#### 3.7 媒体播放保持活跃

- **FR-16：其他应用播放媒体时不进入闲置**
  - 其他应用（Chrome/Safari 网页视频、直播、播放器、音乐等）正在播放媒体时，命中显示器不进入闲置循环播放，避免壁纸覆盖播放内容
  - 命中范围：播放进程的窗口所在显示器；播放进程无窗口（如 Safari 的 WebKit.GPU 子进程播放）时回退命中所有显示器（保守）
  - 媒体开始时若命中屏正处于闲置播放，立即退出让位（**手动「立即播放」的预览除外**：预览期间媒体守卫不生效，任意输入退出后恢复）；媒体暂停或结束后恢复闲置检测（重新挂闲置计时）
  - 不区分视频/音频，任何正在播放的媒体（包括音乐）均触发；已暂停的媒体不触发
  - 不影响微跳：与全屏暂停微跳（FR-03）是两个独立行为，命中屏微跳照常进行
  - 默认开启，可在全局设置「闲置检测」分区关闭
  - 技术实现：基于 MediaRemote 私有框架的「正在播放」信息（通过打包的 perl 辅助组件查询，见技术文档 §3.8）；轮询间隔 2 秒

### 4. 非功能需求

| 需求 | 说明 |
|------|------|
| NFR-01 性能 | 壁纸播放不应显著影响系统性能；空闲时 CPU 占用 < 5% |
| NFR-02 内存 | 每个壁纸窗口内存占用应控制在合理范围 |
| NFR-03 稳定性 | 支持显示器热插拔，不崩溃不残留窗口 |
| NFR-04 兼容性 | 支持 macOS 14+，原生 Apple Silicon 和 Intel |
| NFR-05 分发 | DMG 包分发 + Homebrew Cask 安装 |
| NFR-06 后台监测 | 智能暂停与全屏监测（全屏/显示器睡眠轮询每 2 秒、电源/电量事件驱动）不显著增加功耗与 CPU 占用 |
| NFR-07 开机自启 | 使用系统官方登录项 API，不写入 LaunchAgents plist |

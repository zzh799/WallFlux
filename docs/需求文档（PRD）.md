# 动态壁纸配置程序 — 需求文档（PRD）

## 1. 产品概述

### 1.1 产品定位
一款 macOS 菜单栏工具，智能管理多显示器的动态壁纸。闲置的显示器自动播放动态壁纸保护屏幕，活跃的显示器保持几乎不可察觉的微跳以防止烧屏。

### 1.2 目标用户
macOS 多显示器用户（设计师、开发者、交易员等），希望保护屏幕同时不影响工作流。

### 1.3 核心价值
- **屏幕保护**：闲置显示器自动启用动态壁纸，防止 OLED/LCD 烧屏
- **不打扰**：活跃显示器仅做极微弱的帧跳动，用户几乎无感知
- **多显示器独立**：每个显示器可配置不同壁纸，独立判定闲置/活跃状态

## 2. 功能需求

### 2.1 显示器闲置判定

| 项目 | 说明 |
|------|------|
| 判定方式 | 基于鼠标位置区分：鼠标所在显示器 = 活跃，其他 = 闲置 |
| 键盘行为 | 任意键盘事件使所有显示器变为活跃 |
| 闲置阈值 | 用户可配置，默认 5 分钟，范围 1-60 分钟 |
| 判定精度 | 以秒为单位倒计时 |

**场景示例**：用户在主屏写代码，副屏无操作超过 5 分钟 → 副屏开始播放动态壁纸。

### 2.2 闲置显示器行为

| 项目 | 说明 |
|------|------|
| 播放模式 | 循环播放 |
| 壁纸素材 | 系统自带动态壁纸 + 用户导入的本地视频（mp4/mov/webm）+ 图片序列（帧动画） |
| 开始时机 | 闲置阈值到达后立即开始 |
| 图标可见性 | 桌面图标被壁纸窗口遮挡（接受此行为） |

### 2.3 活跃显示器行为

| 项目 | 说明 |
|------|------|
| 行为模式 | 保留壁纸窗口但暂停播放，每隔 Y 秒向前跳 Z 帧后立即暂停 |
| 微跳间隔 Y | 用户可配置，默认 15 秒，范围 1-300 秒 |
| 跳帧数 Z | 用户可配置，默认 1 帧，范围 1-10 帧 |
| 起始帧 | 从壁纸退出时的最后一帧继续 |

### 2.4 状态切换

#### 闲置 → 活跃（壁纸退出）

| 项目 | 说明 |
|------|------|
| 触发条件 | 鼠标移入该显示器，或任意键盘事件 |
| 退出方式 | 用户可配置：立即停止 / 渐隐过渡（0.5-2 秒可调） |
| 退出后状态 | 进入微跳模式，帧位置保留 |

#### 活跃 → 闲置（壁纸启动）

| 项目 | 说明 |
|------|------|
| 触发条件 | 鼠标离开且超过闲置阈值 |
| 启动行为 | 从当前微跳帧位置恢复循环播放 |

### 2.5 多显示器管理

| 项目 | 说明 |
|------|------|
| 壁纸配置 | 每个显示器可独立选择不同壁纸 |
| 参数配置 | 闲置阈值、微跳参数等全局统一 |
| 热插拔 | 自动检测显示器连接/断开，通过显示器 ID 恢复配置 |
| 显示器命名 | 以系统报告的名称为准（如 "DELL U2723QE"） |

### 2.6 壁纸素材管理

| 项目 | 说明 |
|------|------|
| 系统壁纸 | 自动读取 macOS 动态桌面列表 |
| 导入视频 | 支持 mp4、mov、webm 格式 |
| 导入图片序列 | 选择文件夹，按文件名排序作为帧序列，可配置帧率（默认 30fps） |
| 预览 | 配置界面内置小窗预览 |

## 3. 用户界面

### 3.1 菜单栏

| 项目 | 说明 |
|------|------|
| 图标 | 静态图标，无状态变化 |
| 菜单项 | 显示器状态列表、启用/禁用、偏好设置、退出 |

### 3.2 配置窗口（偏好设置）

- **显示器列表**：显示所有检测到的显示器，每项可展开选择壁纸
- **全局参数**：闲置阈值、微跳间隔、跳帧数、退出方式（立即/渐隐+时长）
- **素材管理**：导入/删除视频或图片序列，预览播放

### 3.3 状态指示

- 菜单栏下拉菜单中，每个显示器名称旁标注当前状态：🟢 活跃（微跳中）/ 🔵 闲置（播放中）/ ⚪ 禁用

---

## 4. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 视频解码使用硬件加速（VideoToolbox），空闲时 CPU 占用 < 5% |
| 内存 | 壁纸窗口单显示器 < 200MB |
| 兼容性 | macOS 14 (Sonoma) 及以上 |
| 启动 | 支持登录时自动启动 |
| 权限 | 需要辅助功能权限（监控鼠标键盘事件） |
